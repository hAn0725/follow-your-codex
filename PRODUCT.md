## Platform

web

## Product Purpose

Codex Meter helps a local Codex user review token volume, estimated API-equivalent cost, capacity, and usage patterns from local session metadata.

## Operating Context

The dashboard runs on localhost and is opened in a browser or through the Windows desktop shortcut. Users compare the preceding 24 hours, 7 days, 30 days, or all recorded history.

## Capabilities and Constraints

The dashboard provides Token and API-equivalent cost trends, quota windows with pace comparisons, model and project breakdowns, expandable daily details, and CSV, Markdown, and JSON exports. Data collection uses local Codex logs. The interface supports Chinese and English, light and dark appearances, and keyboard navigation.

## Brand Commitments

Use the Codex Meter name and existing mark. The November 27 redesign takes direction from Awwwards' homepage typography, spacing, and palette.
